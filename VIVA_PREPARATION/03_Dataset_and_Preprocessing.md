## 3. Dataset Characteristics & Statistical Integrity

### 3.1 Class Imbalance Ratio
- Normal Cases (`0`): **9,661 records (96.61%)**
- Failure Cases (`1`): **339 records (3.39%)**
- **Imbalance Ratio:** Approximately **28.5 to 1**.
- **Impact on ML:** Accuracy paradox occurs. A trivial model predicting constant zeros scores 96.61% accuracy while catching zero breakdowns. Imbalance mitigation is mandatory.

### 3.2 Missing Values & Duplicates
- **Missing Values:** Exactly **0 missing cells** across the 10,000 raw rows.
- **Defensive Engineering:** In `ml_pipeline/train.py`, `df = df[required].dropna().copy()` and `SimpleImputer(strategy='median')` are applied defensively so production telemetry with dropped sensor packets does not cause inference crashes.
- **Duplicates:** Exactly **0 duplicate rows** across the feature set.

### 3.3 Outlier Characteristics & Handling
- `Rotational speed [rpm]` exhibits physical extremes (ranging from 1,168 RPM to 2,886 RPM).
- `Torque [Nm]` ranges from 3.8 Nm to 76.6 Nm.
- Outliers in industrial machines represent mechanical surges (stalls, jams, friction peaks) rather than measurement errors. In MachineMitra:
  - We do not delete outliers because they contain critical failure signals.
  - We use `SimpleImputer(strategy='median')` instead of mean, ensuring that missing values are replaced with robust 50th percentile values unskewed by extreme surges.

## 4. Preprocessing Implementation Details

In `ml_pipeline/train.py`:
```python
prep = ColumnTransformer([
    ('type', OneHotEncoder(handle_unknown='ignore'), ['Type']),
    ('numeric', Pipeline([
        ('imputer', SimpleImputer(strategy='median')),
        ('scale', StandardScaler())
    ]), NUM)
])
```

1. **Categorical Encoding (`OneHotEncoder`):**
   - Ingests `Type` (`L`, `M`, `H`).
   - Generates three binary columns: `Type_L`, `Type_M`, `Type_H`.
   - `handle_unknown='ignore'` ensures that if an unknown type is passed in production, the one-hot transformer outputs all zeros without raising an exception.

2. **Standardization (`StandardScaler`):**
   - Formula: $z = \frac{x - \mu}{\sigma}$
   - Centers each numeric feature around $\mu = 0$ with unit variance $\sigma = 1$.
   - Prevents rotational speed (~1500 RPM) from overpowering torque (~40 Nm) and temperature (~300 K).

3. **Pipeline Encapsulation:**
   - Transformers are fitted strictly on `x_train` during `pipe.fit(x_train, y_train)`.
   - The computed training means ($\mu_{\text{train}}$) and standard deviations ($\sigma_{\text{train}}$) are locked and applied to `x_val`, `x_test`, and production inference, completely preventing data leakage.
